# 安神资料分析系统课思维导图

## 考情分析
- 题量：4篇材料，每篇5题，共20题
- 目标：
	- Sub title
- 阅读技巧
	- 文字型材料
		- 宏观上：不同段落核心内容一般不同
		- 微观上：同一段落，句号表主题，分号表并列
	- 图表型材料
		- 表格：看表头、横纵标目及单位
		- 柱状图/折线图：看图例、双轴含义、年份跨度
		- 饼状图：一般是占比，通常从12点钟方向顺时针排列
	- 综合型材料
		- 特点：文字材料与图表型材料相结合
		- 文字负责“解释和补充”
		- 图表负责“罗列和趋势”

## 基本术语
- 基期与现期：和谁比，谁就是基期
- 同比与环比
	- 同比：与上一年的同一时间节点比较
	- 环比：和相邻的上一个周期比较
- 增长量
	- 表示变化的多少
	- =现期量-基期量
- 增长率
	- 表示变化的快慢
	- =增长量/基期量=（现期量-基期量）/基期量=现期量/基期量 -1
	- 相关表述：增速、增幅、降幅、变化幅度
- 百分数和百分点
	- 百分数：代表两个数量之间的倍数比例关系（例如比重、增长率），用％表示
	- 百分点：是百分数差值形式的表达，专门用来描述两个百分数之间的加减变动量，用百分点表示
- 倍数
	- 注意“多几倍”和“是几倍”
	- 翻番：变成原来的2的n次方，翻3番为8倍
- 比重
	- 比重=部分/整体，部分=整体*比重
	- 一成，表10%
- 平均数
	- 平均数=总量/份数，总量=平均数*份数
- 五年规划
	- 十三五：2016-2020
	- 十四五：2021-2025
	- 十五五：2026-2030
- 顺差与逆差
	- 顺差=出口 - 进口（赚钱＞花销）
	- 逆差=进口 - 出口（花销＞赚钱）

## 核心思维
- 数学思维：一法通万法，只要有“=”，都可以转换
- 选项思维：对照选项，选择答案
- 区间思维：为简化计算，得到的区间
	- 补充：当选项为精确数值时估算，当选项为区间时应该精算

## 计算技巧
- 加法运算技巧
	- 尾数法
	- 高位叠加法
	- 削峰填谷
- 减法运算技巧
	- 整数基准值法
	- “21”“12”分段法
- 乘法运算技巧
	- 直乘估算：选项差距大时，取一个数据当做区间变量，判断乘积区间范围，结合选项判断答案
	- 拆分法：熟练掌握0.1/0.2/0.5/0.25等数据快速计算
	- 乘法分配律：如1.13*1.08=1+0.13+0.08+0.13*0.08
	1.22*0.94=1+0.22-0.06-0.22*0.06
	- 化乘为除（化零为整）：把特定百分数转换成简易分数，如A*16.7%=A/6
		- 常见百化分转换表
- 除法运算技巧
	- 识别误差与截位直除估算
		- 1.首位不同（例如 A.123， B.234）。误差极大，分母四舍五入保留2位计算
		- 2.首位相同，但次位差 ＞ 首位（例如 A.123， B.145。首位是1，次位差是 4−2＝2，2＞1）。误差较大，分母四舍五入保留2位计算
		- 3.首位相同，次位差 ≤ 首位（例如 A.123， B.135。首位是1，次位差是 3−2＝1，1≤1）。误差较小，分母四舍五入保留3位计算
		- 4.差距极小（例如 A.1234， B.1235）。不截位，精算
	- 化除为乘（化零为整）：百化分，如A/16.7%=A*6
	- 定量修正，假设一个较为好算的“目标整数”，进行乘法验证，通过余数修正来精确定位选项区间
- 大小比较
	- 找数、加减比较
		- 注意“单位”、“主体”，耐心、细致最重要
	- 乘法的大小比较
		- 如果A＞B且C＞D，则A*C＞B*D，“大大则大”
		- “一大一小”时
			- 一是直接计算乘积
			- 二是比较两个乘式因子，看谁大的幅度更夸张
	- 除法的大小比较
		- 分子大，分母小，则分数更大
		- 直除，适合首位不同，秒杀
		- 变化幅度比较：分子涨的速度＞分母涨的速度，则分数更大
			- 补充技巧：也可分子或分母配平后再比较
		- 胜率法（盐水法）：大的分子分母减去小的分子分母后的新分数与小的分子分母比值进行比较

## 基期（A）
- 基础公式：A=B/（1+R）=B - X=X/R
- 基期量的计算
	- 第一步：找数。定位材料给出数据
	- 第二步：确定解题思路。结合三个基础公式，根据给出的线索确定计算方法
	- 第三步：看选项。如是减法计算，则确定误差位级；如是除法运算，则确定首位和次位差，决定分母是保留 2 位还是 3 位
	- 第四步：计算。如是减法运算逻辑，结合误差位级，计算并得出答案；如是除法运算逻辑，则根据前面判断的误差区间，
	决定分母保留 2 位还是 3 位，截位直除得出答案，首位不同时直接秒杀
	- 除法计算基期量的进阶计算技巧
		- 退位修正法（适用性广，精算时需利用误差二次运算，对误差辨析要求较高）
			- 误差计算
				- 误差函数图
		- 代入法（选项差距小，或者区间判断题）：选用选项的中间值或者好算的数值，*（1+R），跟题干的现期量进行比较，大了就选小，小了就选大
		- 定量修正法（需要一定的数字敏感性）：假设一个好算的整数作为计算的起点，以此来进行快速的区间判定。如无法选出，再进行余量的修正
- 基期量的比较
	- 加减法：材料给出现期量和增长量
		- 第一步：观察数据，现期量大且增长量小，则基期大；现期量小增长量大，则基期小
		- 第二步：无法排除再进行加减法运算
	- 乘除法：材料给出现期量和增长率
		- 第一步：观察数据，现期量大且增长率小，则基期大；现期量小增长率大，则基期小
		- 第二步：无法排除，运用大小比较技巧（直除、分子分母倍数），一般无需算出具体结果
		- 第三步：当基期量差别特别小时，建议使用替代比较（胜率法）

## 增长量（X）
- 基础公式：X=B - A=A*R=B*R/（1+R）
- 增长量的计算
	- 第一步：找数，定位材料给出数据
	- 第二步：确定解题思路。结合三个基础公式，根据给出的线索确定计算方法
	- 第三步：看选项。如是减法计算，则确定误差位级；如是除法再进行分布计算
	- 第四步：计算
		- 减法运算逻辑，结合选项误差位级，计算并得出答案
		- 除法运算逻辑：
		重要公式：X=B*R/（1+R）
		核心思维：分步计算
			- 直乘修正：先算B*R，再结合选项辨识，可直接➗️（1+R），也可以退位修正
			- 增长率修正：先算R/（1+R），估算首位，再和现期相乘。当B*R相乘运算复杂时可用
			- 代入修正
				- 选项差距大时，计算B/（1+R）估算基期，代入增长率确定答案
				- 选项差距小时，以现期为起点，以选项为变量，确定基期区间，代入增长率确定答案
			- 百化分
				- 受限于“数字巧合”，当r刚好处于两个特殊分数之间时，配合区间思维判定上下限。
- 增长量的比较
	- 加减法：材料一般给出不同年份的当量，作差比较增长量大小
	- 乘除法：材料给出现期量和增长率
		- 第一步：观察数据
			- R都＞0时，现期量大且增长率大，则增长量大；现期量小且增长率小，则增长量大
			- R有正有负时，正增长必然大于负增长
			- R都＜0时，现期量大且降幅大，则减少量大；现期量小且降幅小，则减少量小
		- 第二步，“一大一小”时，先计算B*R，再➗️（1+R），口算结果，一眼差距大则直接出答案
		- 第三步：口算无法出答案时，进行分数比较
			- 对比方法1：分子分母作差比较，类基期替代比较（胜率法）
			- 对比方法2：分别比较分子（B*R）、分母的倍数关系

## 增长率（R）
- 基础公式：R=X/A=（B-A）/A=B/A - 1=X/（B-X）
- 增长率的计算
	- 常规路径：同上，找数，套公式，确定位差，直除
	- 代入：通常出现于判断增长率是否大于某个区间或具体数字的场景
- 增长率的比较
	- 找数的比较：问增幅，带正负号；问降幅，为负增长，带绝对值比较；变化幅度，全部带正负号比较
	- 加减比较：注意 不同的说法
		- 增长率变高：提高、上升、回升、加快
		- 增长率变低：下降、回落、放缓
		- 正增长的幅度变化：增幅扩大/收窄
		- 负增长的幅度变化：降幅扩大/收窄
	- 乘除比较
		- 替代比较：X/B 等效于 X/A
- 复合增长率
	- 基本公式：R=R1+R2+R1*R2
		- 补充：该等式通过移项可得R1=（R-R2）/（1+R2），
		就是平均数增长率公式，两者是相通的
	- 应用场景：凡是符合M*N=P，都可以
		- 间隔增长率
		- 平均数增长率：收入＝人均收入*人数；总花费 ＝ 人均花费*人数；总产值 ＝ 亩产*面积
		- 比重增长率：部分=总体*占比
		- 其他乘式增长率：如销量=产销率*产量，利润=利润率*成交额
		- 算式计算：如计算177/1.29时，可以看成29%+a+29%*a=77%，可以代入选项判断答案
- 混合增长率（盐水）
	- 数学原理：加权平均
		- 原则1：总增率居中。 混合增长率 R，一定介于 R1 和 R2 之间
		- 原则2：偏向基期大者。 谁的基期量（权重）大，R 就更靠近谁。
	- 用法
		- 线段法：画一条线段，左边写小增长率，右边写大增长率。材料中要求的整体增长率，必定落在这两个数值的区间内。
		- 十字交叉法：部分 A 增速 Ra 与混合增速 R 的差值，和部分 B 增速 Rb 与混合增速 R 的差值之比，等于它们基期量的反比
			- Sub title
	- 实战建议
		- 1.借助选项带入。我们可以先画线段，通过选项带入，模拟倍数关系，然后判断二者基期是否可能是该倍数关系（更为推荐）
		- 2.现期代替基期。如果给出的增长率不大（通常＜20％），且两个基期差别不大，那么我们可以考虑忽略误差，直接用现期带入（有较大局限性）
			- 底层原因：现期1＞现期2，不代表基期A一定大于基期B
	- 应用场景
		- 平均类：城镇人口×城镇人均收入＝城镇总收入；农村人口×农村人均收入＝农村总收入；城镇人口＋农村人口＝总人口
		- 基期和差问题
			- 公式：A+（B-A）=B
		- 数量关系中的溶液问题（盐水）

## 综合考察题型
- 年均增长量
	- Sub title
		- 比较大小时，用总增长量代替总增长量/年份间隔
		- 假设增量求后期
			- 如果当前量为 A，每期增长量为 d，则 t 期后：A ₜ＝A＋d*t
			- 按目前增长量，多久后达到某一数值？列式为A＋d*t ≥ T，结果不是整数时，要向上取整
			- 追及问题：A＋d*At≥B＋d*Bt
- 年均增长率
	- Sub title
		- 比较大小时，用现期量/基期量代替R，倍数越大，年均增长率越大
		- 常见年均增长率表
		- 计算：常选项代入，乘积增长率算法
		- 假设增率求后期
			- 固定周期后的量值
				- 常规解法：代入A ₜ＝A（1＋R）ᵗ
				- 进阶解法：利滚利思维，增量的增率
			- 按目前增长率，多久后达到某一数值？
			列式为A（1＋R）ᵗ≥T，先算目标倍数T/A，再选项代入
- 基期倍比
	- Sub title
		- 先计算 A现/B现
			- 1.方向判定：如果Ra＞Rb，说明分子跑得比分母快，则现期倍数＞基期倍数
			- 2.选项编译
				- 法1：一般选项中有个现期倍数，判断方向后，假如还剩下两个选项符合条件，再转换成两期比重差进行计算筛选
				- 法2：乘积增长率
- 两期比重（平均数）差
	- Sub title
		- 先计算Ra -Rb
			- 转换公式，代入选项，适用于问某个范围
- 基期和差
	- 常规解法：分别求出基期，再相加减
	- 先算现期和差，再看增量和差
		- 现期是大头是准确的，增量和差是小头可粗算，需判断增长量变化方向

## 特殊考点
- 拉动增长率与增长贡献率
	- 拉动增长率
		- 含义：某一部分在整体增长中作出的拉动贡献
		- 公式：拉动增长率 = 部分增长量 ÷ 整体基期量，R=x/A
			- 各部分拉动增长率之和为整体R
	- 增长贡献率
		- 含义：某一部分增长量在整体增长量中的占比
		- 公式：增长贡献率 = 部分增长量 ÷ 整体增长量，R=x/X
			- 各部分增长贡献率之和=100%
- 常用统计口径与特殊指标
	- 名义增长率与实际增长率
		- 核心公式：1 + 名义增长率 =（1 + 实际增长率）×（1 + 价格增长率），则实际增长率 =（1 + 名义增长率）÷（1 + 价格增长率）- 1
		- 如果增长率都比较小，可以近似理解为：实际增长率 ≈ 名义增长率 - 价格增长率
	- 生产销售指标
		- 产销率 = 销量 ÷ 产量
	- 人口类指标
		- 自然增长率 = 出生率 - 死亡率
		出生率 = 出生人口 ÷ 年平均人口
		死亡率 = 死亡人口 ÷ 年平均人口
		城镇化率 = 城镇人口 ÷ 总人口
		老龄化率 = 老年人口 ÷ 总人口
	- 企业经营类指标
		- 利润率 = 利润 ÷ 收入
		成本利润率 = 利润 ÷ 成本
		资产负债率 = 负债 ÷ 资产
		主营业务利润率 = 主营业务利润 ÷ 主营业务收入
	- 财政金融类
		- 存贷比 = 贷款余额 ÷ 存款余额
		不良贷款率 = 不良贷款余额 ÷ 贷款余额
		财政自给率 = 一般公共预算收入 ÷ 一般公共预算支出
- 容斥问题
	- 至少满足一项 = A + B - A∩B
	- “只满足 A”或者“只满足 B”，则：只 A = A - A∩B；只 B = B - A∩B
	- 都不满足 = 总体 - A∪B=总体 -（A + B - A∩B）
	- A∩B 至少 = A  + B  - 100%

## 各种坑
- 时间坑：2023 年 / 2022 年，上半年 / 全年，当月 / 累计
- 单位坑：亿元 / 万元，万人 / 人，吨 / 万吨，美元 / 人民币
- 主体坑：全国 / 某省，规模以上 / 全部，城镇 / 农村
- 口径坑：同比 / 环比，现期 / 基期，增长率 / 增长量
- 表述坑：超过 / 不到，至少 / 至多，正确 / 错误，能推出 / 不能推出
